# 业务技术债台账

技术债详细登记见 `mymodules/tk_freight/docs/technical_debt.md`（TD-001 ~ TD-026）。

## 与业务口径强相关的债务

| 债务 | 口径偏差 | 影响 |
|---|---|---|
| TD-001 | 成本按 sale 计算，未用 cost | 供应商账单为供应商原始账单，我方非创建方；已延期，不作为当前闭环技术债 |
| TD-002 | 多币种直接相加 | 外币票利润不准 |
| TD-003 | 发票/费用行无双向追溯 | 作废/红冲不回滚 |
| TD-005 | 账务汇总不随发票状态刷新 | 页面口径不一致 |
| TD-008 | 税费链路缺失 | 开票税额无法承载税率 |
| TD-009 | 开票入口重复/缺关联 | 仪表盘统计不全、重复开票风险 |
| TD-026 | 每日汇率无自动更新 | B-23“当前汇率”依赖手工维护，外币折算可能滞后 |

## 延期事项

- 报表需求、角色权限、门户写权限均待业务确认，不实施。
