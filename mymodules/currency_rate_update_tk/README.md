# currency_rate_update_tk (汇率自动更新扩展)

## 概述
本模块是基于 OCA `currency_rate_update` 的扩展插件。
为了解决原生模块日志过于粗放的问题，本模块采用了**非侵入式**设计，**未修改任何 OCA 基线代码**，确保您的系统在升级 OCA 模块时不会遇到冲突。

**核心特性：**
1.  **逐笔审计日志**：摒弃了原生版的“统计摘要”日志，现在每成功更新一条汇率，都会生成一条独立的明细记录，包含改前值、改后值和执行时间。
2.  **智能日期适配 (ECB)**：针对欧洲央行 (ECB) 数据源的特性（下午发布昨日数据），自动校准抓取日期，解决时区导致的“0条更新”问题。
3.  **精准服务过滤**：新增 `Active for Auto Update` 字段，允许在计划任务中精确控制哪些服务商需要参与自动更新。

---

## 安装指南
1.  将本模块放置在您的 Odoo 自定义模块目录（例如 `mymodules/`）。
2.  更新应用列表 (Apps)。
3.  搜索并安装 **"Currency Rate Update TK Extension"**。
4.  **依赖检查**：确保系统中已安装 `currency_rate_update` (OCA原版)。

## 配置说明

### 1. 服务商 (Provider) 配置
进入菜单：`会计 (Accounting)` -> `配置` -> `货币` -> `汇率更新服务提供商`

*   **基本设置**：配置常规信息（名称、服务类型、API 密钥等）。
*   **⚙️ 关键配置项**：
    *   **Active for Auto Update**：勾选此项，该服务商才会被系统的每日计划任务（Cron）自动触发。
    *   *(注：原版的 `Active` 字段依然控制手动按钮的显示)*。

### 2. 查看更新日志
本模块添加了新的菜单，用于审计：
*   **菜单路径**：`会计 (Accounting)` -> `配置` -> `货币` -> `汇率更新日志`
*   **功能**：这里会列出每一次汇率变动的详细流水。您可以清楚地看到哪条记录在哪一天被更新成了什么值。

## 技术亮点 (Developer Notes)
为了保持与 OCA 基线的完全解耦，本模块采用了高级 ORM 继承技巧：

*   **Mixin 注入**：通过 `models.Model` 的 `_inherit` 机制，向原生 `res.currency.rate` 注入了自定义的 `create` 和 `write` 方法。
*   **上下文标记**：在执行更新时注入 `skip_auto_log=True`，有效防止了日志记录的无限递归。
*   **兼容性**：所有改动均位于 `currency_rate_update_tk` 命名空间下，符合 AGPL 合规要求。

## 问题排查 (Troubleshooting)

**Q: 为什么配置了 ECB 提供商，但早上 8 点运行时没有更新数据？**
*   **A**: ECB 通常在欧洲中部时间下午 14:10 发布前一天的数据。本模块的 Cron 默认设置为早上 7:30 运行，此时数据可能尚未发布。模块已内置时区转换逻辑，如果您希望更晚执行，请在计划任务中调整时间。

**Q: 我想临时手动更新一次汇率，但不想产生日志，可以吗？**
*   **A**: 可以。在手动更新的 Wizard 界面中，通常会有一个选项（取决于原生模块），或者在开发者模式下调用方法时移除特定的上下文参数即可跳过。
